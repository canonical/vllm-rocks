# vllm-rocks

Canonical [rocks](https://documentation.ubuntu.com/rockcraft/) (OCI images built
with Rockcraft) for [vLLM](https://github.com/vllm-project/vllm).

| Rock | Description |
| --- | --- |
| [`vllm-cpu`](vllm-cpu/) | vLLM inference server, CPU-only (amd64) |
| [`vllm-cuda-gpu`](vllm-cuda-gpu/) | vLLM inference server for NVIDIA GPUs (CUDA, amd64) |

Each directory has its own `rockcraft.yaml`, tests and README.
